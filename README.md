CarePath
Post-Discharge Recovery & Care Coordination Platform

CarePath is a web-based platform designed to support patient recovery after hospital discharge. It allows patients to submit daily recovery check-ins and helps healthcare professionals review progress, track recovery trends, and identify entries that may require attention.

Core Features
- Patient Management
- Recovery Plan Management
- Daily Patient Check-ins
- Recovery Analytics and Timeline
- Rule-Based Alert System
- Doctor Dashboard

 Technology Stack
- Frontend: React.js
- Backend: Node.js and Express.js
- Database: MySQL
- Authentication: JWT and bcrypt
- Data Visualization: Recharts
- API Testing: Thunder Client or REST Client

Project Workflow
Hospital Discharge → Recovery Plan Creation → Daily Patient Check-ins → Recovery Trend Analysis → Rule-Based Alerts → Doctor Review

Development Plan
- Week 1: Planning and design
- Week 2: Core development
- Week 3: Integration, testing, demonstration, and final presentation
Data and Safety
The project uses synthetic patient records and recovery data for development and demonstration. CarePath supports recovery monitoring and care coordination; it is not intended to diagnose medical conditions or replace professional medical care.
